# LearnLyt – Knowledge Retention Tool

LearnLyt is a beginner-friendly, menu-driven Python application for storing, organizing, searching, and maintaining learning notes.

## Features
- Add, view, search, update, and delete notes
- Organize notes by subject/category
- Save data persistently in a JSON file
- Generate a summary report showing total notes and notes per category
- Uses Python lists, dictionaries, loops, functions, conditionals, and file handling

## Requirements
- Python 3.8 or newer
- No third-party libraries required

## How to run
1. Extract the ZIP file.
2. Open the `LearnLyt_Project` folder in VS Code.
3. Open a terminal in that folder.
4. Run:

   ```bash
   python learnlyt.py
   ```

5. Choose an option from the menu. The file `learnlyt_data.json` will be created automatically when you save your first note.

## Project workflow
User → Menu → Select operation → Process note → Save to JSON → Display result

## Important
This is a console-based implementation based on the supplied LearnLyt materials. It does not include AI-based automatic summarization, spaced repetition, or a graphical interface.
