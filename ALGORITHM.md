# LearnLyt Algorithm

1. Start the application.
2. Load existing notes from `learnlyt_data.json` if the file exists.
3. Display the menu.
4. Read the user's choice.
5. If the choice is Add, collect title, category, and content; assign an ID; save the note.
6. If the choice is View, display all saved notes.
7. If the choice is Search, find notes matching the keyword in title, category, or content.
8. If the choice is Update, find a note by ID, update the entered fields, and save changes.
9. If the choice is Delete, ask for confirmation and remove the selected note.
10. If the choice is Summary Report, display total notes and counts by category.
11. If the choice is Exit, end the program.
12. Otherwise, show an invalid-choice message and return to the menu.
13. Repeat steps 3–12 until the user exits.
